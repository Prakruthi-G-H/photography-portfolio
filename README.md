# 📸 Photography Portfolio

A responsive photography portfolio website built using HTML5 and CSS3 to showcase photographs in a clean, elegant, and user-friendly interface.

The project demonstrates responsive web design, semantic HTML, CSS layouts, and organized image gallery presentation.

## 🌟 Features

- 🏠 Home section with an attractive background image
- 🖼️ Image grid layout to display photographs neatly
- 🙋‍♀️ About Me section
- 📬 Contact form with Name, Email, and Message fields
- 📱 Responsive Design – Adapts to different screen sizes and devices
- 🎨 Clean UI – Simple and visually appealing photography-focused design

## 🛠️ Technologies Used

- **HTML5** – Semantic structure and webpage content
- **CSS3** – Styling, layouts, image gallery, and responsive design
  
## 📁 Project Structure

```
Photography-Portfolio/

```

## 🚀 How to Run

1. Download or clone the repository:  
  ```bash
git clone https://github.com/Prakruthi-G-H/photography-portfolio.git
```
2. Open the folder in any browser or use Live Server in VS Code  
3. Open `index.html` to view the homepage  
4. No backend or server setup required
